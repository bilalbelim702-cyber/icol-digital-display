Use a fine-grained GitHub token for the ICOL repository. This page keeps it in memory until you lock the editor or leave the page.

Set up access
  1. Sign in to GitHub and create a fine-grained token with an expiration.
  2. Choose Only select repositories and select icol-digital-display.
  3. Set Contents to Read and write, then generate the token.
  4. Copy the token into the field above on this page. Keep it private.
